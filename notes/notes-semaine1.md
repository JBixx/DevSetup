# Notes Semaine 1

Objectif : Mettre en place les outils de base et comprendre le workflow Git.

## Ce que j'ai installé

- Node.js 20 LTS : runtime JavaScript côté serveur
- Git : gestion de versions
- VS Code : éditeur principal avec les extensions ESLint et GitLens
- GitHub CLI : pour interagir avec GitHub depuis le terminal

## Commandes Git retenues

```bash
git status          # voir l'état du dépôt
git add .           # indexer les modifications
git commit -m "msg" # enregistrer un commit
git push            # envoyer vers GitHub
git pull            # récupérer les changements distants
git log --oneline   # historique condensé
```

## Difficultés rencontrées

La configuration initiale de Git (user.name et user.email) m'a pris un moment. J'ai aussi confondu git add et git commit au début, il faut bien comprendre que add prépare et commit enregistre.
