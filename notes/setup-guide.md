# Setup Guide

## Git
Installer Git pour versionner le code. Config rapide :

```bash
git config --global user.name "Ton Nom"
git config --global user.email "email@example.com"
```

Commandes de base : init, add, commit, push, pull. C'est tout ce qu'il faut pour commencer.

## VSCode
Télécharger VSCode, c'est l'éditeur qu'on va utiliser. Ajouter quelques extensions utiles comme Prettier (formateur auto) et GitLens.

Activer le format on save, ça évite de penser à bien formatter le code.

## Node.js
Installer Node (LTS) pour exécuter du JavaScript en dehors du navigateur. NPM vient avec.

Commandes principales : npm init, npm install, npm start. 

## Terminal
On utilise plusieur commande. Il faut connaître : cd, ls, mkdir, rm. Rien de compliqué.

## Checklist
- Git
- VSCode
- Node.js
- Terminal
- GitHub créé

Voilà, après on peut commencer.
